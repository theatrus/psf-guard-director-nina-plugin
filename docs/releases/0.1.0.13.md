# Director 0.1.0.13 beta

While waiting for a target to become observable, Director checks PSF Guard
for activated plan changes every 30 seconds. Activate a new plan for the rig
in PSF Guard. Director requests updated work automatically and starts an
eligible exposure. Saved images still count toward each plan.

At startup, Director waits for the safety monitor to report Safe or for the
enclosure to open. It starts automatically when conditions allow. The Status
and Activity tabs explain when a target is observable later or PSF Guard is
still grading saved images.
