# Director 0.1.0.2 preview

Experimental acquisition preview for N.I.N.A. 3.3 nightly #58 or newer on
Windows x64. Tested on nightly #65 (3.3.0.1065). Do not use for unattended
imaging. PSF Guard Sync is unchanged.

## Acquisition

- Pair with PSF Guard using a Director code; credentials stay in Windows
  Credential Manager and are never displayed.
- Add Director Session to the Advanced Sequencer with seven TS-style
  instruction slots, native triggers/conditions and grouped local policies.
- Run bounded, local multi-target schedules using the shared Rust core,
  project rankings, Moon avoidance and configured observing preferences.
- Request commissioned workloads automatically and wait for eligible work or
  quality assessment without refilling spent attempt budgets.
- Use NINA's centering, rotation, autofocus, guiding, dithering and checked
  meridian-flip flow, or retain explicit sequence ownership for custom actions.
- Inspect the target's horizon chart and timed actions in the Activity tab
  and NINA log. Report equipment capabilities for operator review.

## Check-in and safety

- Choose live or deferred check-ins. Deliver saved runs from settings, the
  Director Check In action, or the next session without repeating acknowledged
  events. Continue an authorized local workload during coordinator outages.
- Apply changed project rankings at safe live check-in boundaries; finish the
  current exposure, park and reconcile before requesting new work.
- Choose park or stop/tracking-off on abort. Enclosure closure or lost clearance
  blocks parking. Changed site, horizon or meridian settings stop acquisition;
  restored conditions do not restart it automatically.
- Stop on failed native preparation or flip workflow steps and name failed
  automatic triggers in errors.

## Validation and limits

The bundled runtime is 0.10.0, planning engine 0.3.0, contract 2 and IPC 10.
All 827 automated tests and 14 isolated NINA/PSF Guard simulator scenarios
passed before release preparation. Coverage includes offline/deferred check-in,
priority refresh, Moon wait, safety/enclosure/constraint stops, failed native
operations, 30-degree rotation, PHD2 guide recovery and resumed capture after
a native meridian flip. See [validation evidence](../nina-smoke-test.md).

Optical focus and solve results in the simulator are synthetic. Real-sky
solving/focus, physical guide calibration across flips, weather, full-night
operation and broad third-party compatibility remain acceptance work.
Restart/resume and uncertain-run recovery remain unavailable. Acquisition
requires explicit commissioning, launch authority and local safety/enclosure
configuration. Installing or pairing the plugin does not authorize capture.

The ZIP includes the verified runtime and license notices; test helpers are
excluded. Installation does not depend on development CI artifacts remaining
available. Director remains experimental even though the shared registry feed
does not support a separate preview channel.
