# Director 0.1.0.15 beta

- Choose **Upload captured frames to PSF Guard** in Director plugin settings to send the light files saved by a Director Session. Uploads default **off** for new and existing profiles. Live and Deferred image record delivery work independently, so you can keep using another file transfer method.
- Turning uploads off pauses queued files and cancels the current transfer. Turning them on resumes files for the active profile and pairing. Files saved while uploads were off are not added later. Retry and Forget affect only that connection and never delete image files.
- Uploads run in the background, keep queued files through restarts and server outages, and require confirmation from PSF Guard before marking a file complete. Duplicate uploads do not create another copy of the file.

File uploads require a PSF Guard server build that includes [Director upload support (#1086)](https://github.com/theatrus/psf-guard/pull/1086). Also enable **Image uploads** for the database in PSF Guard. An older server keeps files queued without interrupting imaging or image record delivery.

This beta passed 1,162 managed tests and native N.I.N.A. 3.2 simulator tests with the bundled Rust runtime and an isolated PSF Guard server. Uploads off sent no files; uploads on delivered three files with matching SHA-256 hashes and correctly identified a repeated upload. Full-night testing on real equipment remains open.
