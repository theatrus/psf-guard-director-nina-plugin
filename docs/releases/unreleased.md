# Unreleased

- Choose **Upload captured frames to PSF Guard** in Director plugin settings to send the light files saved by a Director Session. It defaults off for new and existing profiles; Live image record delivery works independently. Turning uploads off pauses the queue and cancels the current transfer. Turning it on resumes files for the active profile and pairing. Retry and Forget affect only that connection, and never delete image files. Also enable **Image uploads** for the database in PSF Guard.
