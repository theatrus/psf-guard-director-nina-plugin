# Director 0.1.0.20 beta

- Director checks whether PHD2 is already guiding before starting it. Checks between exposures and after dithers no longer produce redundant "guiding started" events. Guiding still starts when needed, and deliberate recalibration still stops and restarts it.
- Other plugins can receive Director's target and wait events in the Target Scheduler message format. Enable **Other plugins → Send Target Scheduler compatible events** in Director settings. This option is off by default, retains Director's identity, and works without Target Scheduler installed.
- A failed or unresponsive event subscriber cannot keep delaying imaging. Wait notifications include the reason and an estimated next check time.

Director remains a beta. The bundled runtime remains 0.15.0; no PSF Guard Sync changes are included.
