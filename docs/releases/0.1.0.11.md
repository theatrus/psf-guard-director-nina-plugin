# Director 0.1.0.11 beta

Director uses PSF Guard's clock to check workload windows and calculate sky
positions. A rig clock that is minutes or hours ahead or behind can still
start a valid workload. PSF Guard checks that the grant is current and
authorizes its launch once. Director still enforces the configured maximum
session duration.

This beta also includes the sequence activity and status changes from 0.1.0.10.
