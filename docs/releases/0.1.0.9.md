# Director 0.1.0.9 — beta

Director Session requests work from PSF Guard and selects targets automatically.
The separate **Automatic workloads** and **Local target scheduling** switches
are removed from the editor. Existing saved sessions use this workflow when
loaded. New sessions keep **Enable acquisition** off until you turn it on.

Before a run, the header explains whether acquisition is off or has not started.
Startup checks run when you start the sequence; there is no separate arm button.
Errors appear in the session and Activity tab as well as the N.I.N.A. log.

A new Run automatically recovers previous observing-night records and stale
work requests. Director confirms idle equipment, stops mount motion and guiding,
delivers saved receipts, retires the old server assignment and requests fresh
work using current image counts. Images and history remain available. Acquisition
failures retry within the original Run deadline; terminal errors appear in the
session and abort instead of skipping into shutdown.

Equipment reporting runs automatically at startup. With the matching PSF Guard
server update, reports apply without manual acceptance and keep work permission.
The server update must be installed before using automatic session recovery.

Weather holds continue to record their budgets before waiting for work.
