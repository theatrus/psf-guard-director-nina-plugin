# Director 0.1.0.17 beta

- Director checks current safety and target conditions after long global triggers such as autofocus. The next exposure no longer fails with **Unexpected ledger result** simply because the trigger took longer than 30 seconds.
- An old global autofocus failure no longer fails later target setup or wait instructions, preventing repeated park/restart cycles. New failures still stop the current block, and the error identifies the instruction that failed.
- Local safety and recovery checks tolerate differences between the observing PC's clock and PSF Guard's clock. Safety freshness and assignment deadlines retain their existing limits.
- Both Director pages show the current action, including inherited triggers such as Inject Autofocus. PSF Guard also receives sequence activity before and after Director Session.
- The Overview is simpler, settings are grouped and aligned, and status text follows N.I.N.A.'s font size and active palette. Trigger and condition editors show their normal N.I.N.A. controls.
- Autofocus at target start and after filter changes have separate settings. Existing sequences keep both defaults, and Sequence ownership remains respected.

Update through N.I.N.A.'s plugin manager and restart N.I.N.A. The package includes runtime 0.15.0 / IPC 15; no separate runtime installation is needed. Image uploads remain off by default.

The combined changes passed 1,243 managed tests, five recovery stress runs, and native N.I.N.A. 3.2.0.9001 validation with the bundled runtime and an isolated PSF Guard server. The native test saved three FITS images across two targets after a 35-second global trigger, retained an old trigger failure without restarting, and verified sequence activity and recovery after a server outage. Simulated devices and synthetic optical results were used. Director remains a beta; full-night testing on real equipment remains open.
