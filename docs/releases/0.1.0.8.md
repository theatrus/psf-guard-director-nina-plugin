# Director 0.1.0.8 — beta

**Report equipment** now includes N.I.N.A.'s default gain and offset. With a
PSF Guard server that supports camera defaults, exposure templates set to
`-1` use those accepted values. To update a rig, report equipment again,
accept the report in PSF Guard, and allow work again.

Older servers receive the equipment report using the existing format.
Recipes continue to carry explicit camera settings.
