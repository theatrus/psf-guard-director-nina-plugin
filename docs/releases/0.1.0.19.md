# Director 0.1.0.19 beta

- Fix slow startup after an update caused by rechecking already-reported runs. The old reporting record depended on the bundled runtime version, so the runtime upgrade could make unchanged history look new.
- Keep reporting records across runtime upgrades and migrate the records written by 0.1.0.16 through 0.1.0.18 automatically. Changed or unsent records still receive the normal checks; images and history are preserved.
- Show progress for unsent image records instead of counting historical runs in the startup/settings status. Detailed checked/skipped counts remain in the log.

Validation: 1,272 managed tests passed. Full native N.I.N.A. 3.2.0.9001 validation with the packaged plugin, bundled runtime and isolated PSF Guard confirmed that 120 pre-upgrade runs are skipped without reopening a runtime or contacting the server. The same test verified delayed-trigger recovery, saved images, and delivery/release after a simulated server outage.

Update through N.I.N.A.'s plugin manager and restart N.I.N.A. No history cleanup is needed. This remains a beta and includes the calibration and recovery features from 0.1.0.18. Runtime 0.15.0 / IPC 15 is bundled; image uploads and calibration remain off by default.
