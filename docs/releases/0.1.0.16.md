# Director 0.1.0.16 beta

- Saved-run check-in skips unchanged runs whose records were already sent, including empty failed runs. It no longer starts a runtime for every historical run on every check.
- Changed records, failed deliveries and pending completion reports still retry. Images and run history remain on disk.
- History checks run in the background, and plugin settings show when saved records are up to date and how many unchanged runs were skipped.

Existing history needs one successful check after updating. Later checks verify local files and skip unchanged records.

The fix passed 1,183 managed tests, five recovery stress passes, and native N.I.N.A. 3.2 simulator tests with the bundled Rust runtime and an isolated PSF Guard server. Tests covered offline delivery, assignment completion, deferred delivery, and new plan activation while waiting. Repeated checks succeeded without a runtime or network requests. Director remains a beta; full-night testing on real equipment remains open.
