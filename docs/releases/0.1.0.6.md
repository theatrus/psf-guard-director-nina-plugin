# Director 0.1.0.6 — beta

- Choose **Attended operation** to run with no safety monitor configured in
  your N.I.N.A. profile. Select **I will supervise this attended run** before
  each **Run**. Director still checks any configured monitor and verifies
  enclosure clearance.
- Open **Coordinator** in Director's plugin settings to see when PSF Guard
  accepts the equipment report sent in this N.I.N.A. session.
- Use **Report equipment** while you resolve conflicting sequence triggers.
  If the report fails, Director shows the reason beside the button. Before
  acquisition, Director identifies overlapping instructions and inherited
  triggers and shows which ownership setting to change.
- The **Capture delivery** tooltip explains that Director sends capture records
  and saves image files locally.
