# Director 0.1.0.21 beta

- Director can recover a pointing offset by recentering within the current assignment, preserving saved images and the original session end time. It allows one recenter before a successful science image resets the retry allowance. Repeated offsets or a failed recenter stop with a measured, actionable error instead of repeatedly parking and unparking.
- Waiting at the end of an assignment now explains when no exposure fits before the session ends. Director keeps checking for newly activated plans while waiting and finishes at the original deadline.
- Save reusable session defaults in the N.I.N.A. profile and explicitly load or save them from a Director Session. Existing saved sequences retain their settings; new sessions start with acquisition disabled.
- Configure separate minutes before and after meridian transit. PSF Guard projects can inherit or override either margin, including zero, with a server containing PSF Guard #1097. Native meridian-flip handling remains separate.

Director remains a beta. The bundled runtime is 0.15.0, built from PSF Guard commit `ee5d1a1ff567ffa431ea10ea5be2a5af9b7abe50`. PSF Guard Sync is unchanged.
