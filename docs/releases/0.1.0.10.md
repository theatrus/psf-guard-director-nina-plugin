# Director 0.1.0.10 beta

Director Session shows when it is waiting its turn in a running sequence.
Paired rigs report active Advanced Sequencer instructions to PSF Guard before
and after the session, including when the sequence has no Director Session.
Turn off **Report sequence activity to PSF Guard** in Director's plugin
settings to stop these reports.

A difference between the rig and server clocks no longer causes Director to
reject and repeatedly replace a workload because of the server's admission
timestamp. Director still checks the observing window and waits briefly if
a new window has yet to open. If the reply is invalid, Director stops and
shows the reason.
