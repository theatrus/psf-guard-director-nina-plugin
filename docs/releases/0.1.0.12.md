# Director 0.1.0.12 beta

Click **Run** to start with the saved **Attended operation** safety policy.
Director no longer asks for a separate confirmation before every run. If
the active N.I.N.A. profile has a safety monitor configured, Director
requires a fresh Safe reading.

Director can install and remove native autofocus, guiding, and meridian
flip triggers while the N.I.N.A. sequencer is open.
