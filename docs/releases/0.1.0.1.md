# Director 0.1.0.1 preview

Experimental runtime preview for N.I.N.A. 3.3 nightly #58 or newer on Windows
x64. Acquisition is not yet available. Do not use Director to run an unattended
imaging session. PSF Guard Sync is unchanged.

- Updates the verified bundled Rust runtime to 0.6.0 with IPC 7.
- Adds internal durable execution, site/horizon/meridian constraints, recovery,
  and post-hook dispatch checks for future acquisition support.
- Keeps the visible experience limited to explicit runtime Start/Stop and
  status. Pairing, server assignments, and a production sequencer container
  remain unavailable.

Validation includes the plugin unit/integration suite and a real isolated
N.I.N.A. nightly session with ASCOM simulators, three saved RGB exposures,
native hooks, sidecar restart, and horizon-change detection. That test used a
local fixture assignment, not PSF Guard authorization. Full-stack acceptance
with PSF Guard remains outstanding.

The bundle includes its pinned runtime and license notices. Installation does
not depend on the development CI artifact remaining available.
