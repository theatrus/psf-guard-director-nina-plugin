# Director 0.1.0.18 beta

- Director opens a connected motorized flat-panel cover before centering, autofocus and light exposures. You can choose to close it when the session ends.
- Add **Director Flats** before or after **Director Session**, or schedule panel flats before/after astronomical dusk in **Settings → Flat panel and calibration**. Flats use the filters and camera settings from active plans, including plans whose light frames are complete.
- Flat batches survive restarts. Invalidate coverage in PSF Guard to request replacement flats; Director syncs the request and confirmation while keeping the original files.
- Capture optional darks while no target is ready or during weather holds. Combine active-plan exposure settings with extra exposure lengths and temperature steps. Director restores camera settings before returning to light frames. Calibration is off by default and does not count toward light goals or use the science-image upload queue.
- Includes the 0.1.0.17 fixes: long autofocus triggers no longer cause **Unexpected ledger result**; old trigger failures no longer cause repeated parking/restarts; recovery tolerates server/PC clock differences; and both Director pages show current sequence and trigger activity with compact N.I.N.A. styling. Autofocus at target start and after filter changes have separate settings.

Update through N.I.N.A.'s plugin manager and restart N.I.N.A. Calibration requires the current PSF Guard server with Director calibration support. The package includes runtime 0.15.0 / IPC 15; no separate runtime installation is needed. Image uploads remain off by default.

Validation: 1,269 managed tests and Windows CI passed. A full native N.I.N.A. 3.2.0.9001 simulator run with the bundled runtime and an isolated current PSF Guard server verified scheduled flats, idle darks, three light images across two targets, flat invalidation/replacement without duplicates, recovery after a failed autofocus, and continuation after a 35-second global trigger. Director remains a beta. Physical flat-panel photometry and full-night testing on real equipment remain open.
