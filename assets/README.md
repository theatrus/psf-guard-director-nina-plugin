# Director icon

Director's shield shows a violet D and a gold route to a star. The SVG is the
source for the 256-pixel PNG.

Render the PNG with `cairosvg psf-guard-director.svg -o psf-guard-director.png --output-width 256 --output-height 256`.

The assembly metadata and registry manifest use `psf-guard-director.png` as
their featured image so NINA shows it in the plugin manager.
